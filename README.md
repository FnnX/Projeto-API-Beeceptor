## Objetivo
Adaptar o mural virtual desenvolvido em sala para uma nova API, buscando entender as suas respostas e adicionando personalizações autorais para não se limitar à reutilização do código anterior 

## Como executar
Selecionar o arquivo index.html e clicar em Run and Debug

## API utilizada
Beeceptor | link:
https://json-placeholder.mock.beeceptor.com/posts

## Personalização implementada:
Tratamento de singular e plural na mensagem de resultado;
Organização de publicações de acordo com os números de comentários;
Um contador que soma a quantidade de comentários de todas as publicações exibidas
